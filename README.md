# CSET343 - AI in Healthcare

## Course Overview

**Course Name:** AI in Healthcare  
**Course Code:** CSET343  
**Program:** B.Tech  
**Type:** Specialization Elective  
**Year:** 4th Year  
**Semester:** VII  

This repository contains laboratory experiments and assignments completed as part of the **AI in Healthcare** course.

The practical work focuses on applying data science and machine learning techniques to healthcare data, including:

* Clinical tabular data
* Medical text
* Medical images
* Physiological signals
* Data preprocessing and cleaning
* Feature engineering
* Classification models
* Model evaluation
* Healthcare-specific data interpretation
