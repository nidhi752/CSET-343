## Objective / Agenda

Perform data acquisition, cleaning, preprocessing and analysis on Tabular, Textual, Image, and Signal medical health data.

### Objectives

- Acquire and inspect real-world medical datasets across four different modalities.
- Apply modality-specific cleaning techniques, including healthcare-specific concerns like implausible clinical values, PHI (Protected Health Information) removal, and imaging metadata anonymization.
- Preprocess each data type into a model-ready format (scaled tensors, token sequences, image tensors, signal windows).
- For Tabular data, perform Hypothesis Test, Chi-square Test and ANOVA.
- Perform exploratory data analysis (EDA) appropriate to each modality.
- Apply Feature Engineering, Feature Selection & Extraction Noise Removal, Augmentation on relevant parts.
- Understand why healthcare data requires extra rigor compared to generic datasets (missingness encoded as valid-looking values, class imbalance, privacy constraints, signal noise).
